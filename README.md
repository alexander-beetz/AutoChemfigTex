# mol2chemfig-helper

Small command-line tool for the workflow in the parent project: convert a
SMILES/InChI/PubChem structure with `mol2chemfig`, wrap the result in named
LaTeX macros, and append it to `structures.tex`.

By default `\Name` draws **the structure plus its compound label**, so schemes
can simply say `\Azid + \Alkin`. The label follows the document convention

```latex
\textbf{\cmpd{...}}
```

and can include an optional sum formula and molecular weight without repeating
them at every use site.

## What it generates

For

```bash
m2c-structure 'CN=[N+]=[N-]' Azid . --formula 'CH3N3' --mw '57.05'
```

the tool appends this block:

```latex
% === mol2chemfig-helper:Azid:BEGIN ===
% Generated by mol2chemfig-helper; do not edit this block manually.
% identifier: direct CN=[N+]=[N-]
% mol2chemfig options: -f -w -i direct
% style: named
% sum formula: CH3N3
% molecular weight: 57.05
\newcommand{\AzidName}{%
  \shortstack[c]{%
    \textbf{\cmpd{Azid}}\\
    CH3N3\\
    57.05%
  }%
}

\DeclareRobustCommand{\AzidStructure}{%
  \chemfig{...}%
}

\DeclareRobustCommand{\Azid}{%
  \chemname{\AzidStructure}{\AzidName}%
}
% === mol2chemfig-helper:Azid:END ===
```

Use it directly:

```latex
\schemestart
  \Azid + \Alkin
\schemestop
```

- `\Azid` is the structure with the compound label, formula and molecular
  weight underneath.
- `\AzidName` is the label used by `\Azid`. It contains
  `\textbf{\cmpd{Azid}}` and, when supplied, the formula and molecular weight.
- `\AzidStructure` is the bare structure for one-off custom labels:

  ```latex
  \chemname{\AzidStructure}{\shortstack[c]{Custom\\CH3N3}}
  ```

Without `--formula` or `--mw`, `\AzidName` is simply:

```latex
\newcommand{\AzidName}{%
  \textbf{\cmpd{Azid}}%
}
```

`\cmpd` is not defined by this tool. Load a package that provides it, normally
`chemnum`, or define a compatible macro yourself.

## Requirements

- Python 3.9 or newer
- `mol2chemfig` on `PATH` (`pip install mol2chemfigPy3` in a virtualenv), or
  pass `--mol2chemfig /path/to/mol2chemfig`
- `structures.tex` inside the target directory, unless you pass `--create`
- In LaTeX: `chemfig`, and a definition of `\cmpd` such as `chemnum`

## Installation

From this directory, either run it directly:

```bash
python3 -m mol2chemfig_helper 'SMILES' Azid /path/to/thesis
```

or install the console script:

```bash
python3 -m pip install -e .
m2c-structure 'SMILES' Azid /path/to/thesis
```

The `m2c-structure` file in this directory also works without installation:

```bash
./m2c-structure 'SMILES' Azid /path/to/thesis
```

## Usage

```text
m2c-structure IDENTIFIER NAME [DIRECTORY] [options]
```

| Option | Meaning |
| --- | --- |
| `-C, --dir DIR` | target directory, as an alternative to the third positional argument |
| `--file NAME` | file inside the target directory (default `structures.tex`) |
| `--format direct\|file\|pubchem` | how `mol2chemfig -i` should interpret the identifier (default `direct`) |
| `--label KEY` | key passed to `\cmpd{...}` (default: `NAME`) |
| `--formula TEXT` | sum formula added to `\NameName` |
| `--mw TEXT` | molecular weight added to `\NameName` |
| `--structure-only` | make `\Name` the bare structure; no `\NameStructure` macro |
| `--mol2chemfig PATH` | mol2chemfig executable |
| `--m2c-arg ARG` | extra mol2chemfig option, repeatable |
| `--terse` | add `-z` for terse chemfig output |
| `--overwrite` | replace an existing definition without asking |
| `--dry-run` | show the diff but do not write |
| `--backup` | write `structures.tex.bak` before changing the file |
| `--create` | create `structures.tex` if missing |
| `--timeout SECONDS` | mol2chemfig timeout (default 120) |
| `--quiet` | do not print the diff |

Examples:

```bash
# Normal case
m2c-structure 'C1=CC=CC=C1O' Phenol ~/thesis

# Add formula and molecular weight to \PhenolName
m2c-structure 'C1=CC=CC=C1O' Phenol ~/thesis \
  --formula 'C6H6O' --mw '94.11'

# Different \cmpd key
m2c-structure 'C1=CC=CC=C1O' Phenol ~/thesis --label phenol

# PubChem CID, terse output
m2c-structure 996 Caffeine ~/thesis --format pubchem --terse

# Preview only
m2c-structure 'CCO' Ethanol ~/thesis --dry-run

# Old structure-only \Name macro
m2c-structure 'CCO' Ethanol ~/thesis --structure-only

# Replace an existing \Ethanol
m2c-structure 'CCO' Ethanol ~/thesis --overwrite
```

`--formula` and `--mw` are inserted as LaTeX exactly as you write them. Use
whatever your document needs, for example `C6H6`, `$C_6H_6$`, `\ce{C6H6}`, or
`C\textsubscript{6}H\textsubscript{6}`. They must be single-line text.

`--label` is the `\cmpd` key, not the printed text. It may contain ASCII
letters, digits, `.`, `_`, `:` and `-`, and must not start with punctuation.
The default is the structure name.

## Duplicate handling

Before writing, the tool prints a unified diff. If the name already exists, it
shows the existing definition and asks:

```text
  [o] Overwrite existing definition
  [n] Enter a new name
  [a] Abort
```

- Managed blocks are replaced in place.
- A simple, standalone hand-written definition such as
  `\DeclareRobustCommand{\Azid}{...}` can also be replaced.
- Complex definitions (`\let`, multiple definitions, definitions sharing a
  line with other code) are not rewritten automatically. Choose a new name
  instead.
- If the same identifier is already stored under another name, a warning is
  printed but the new structure is still added.
- A name that collides with another block's generated `\NameName` or
  `\NameStructure` macro is also treated as a conflict.
- Non-interactive use requires `--overwrite` for an existing name; otherwise
  the command exits with an error.

## Notes and limitations

- `\Name` now includes the compound label. Do not write
  `\chemname{\Azid}{...}` any more; use `\Azid` directly, or use
  `\chemname{\AzidStructure}{...}` for a custom label.
- Existing blocks generated by older versions define a structure-only
  `\Name`. Re-running the tool for that name shows a diff and asks before
  replacing the block. Update any `\chemname{\Azid}{...}` call sites to
  `\Azid`.
- `\NameName` uses `\textbf{\cmpd{...}}`. Load `chemnum` or provide a
  compatible `\cmpd` definition.
- Formula and molecular weight are not computed; they are user-supplied.
- Do not edit inside a `mol2chemfig-helper` BEGIN/END block by hand; the next
  run replaces the whole block. Edit outside the markers instead.
- The parser is deliberately not a full TeX parser. It handles normal
  `\newcommand`, `\DeclareRobustCommand`, `\def` and xparse command
  definitions, braces, escapes and line comments.
- The identifier is passed to `subprocess` as one argument, never through a
  shell. A `--` separator protects identifiers that begin with `-`.
- Writes are atomic and preserve the file's line endings, UTF-8 BOM and mode.
  `--backup` additionally keeps a copy of the previous file.
- The target file must be a plain filename inside the target directory;
  symlinks leading outside that directory are rejected.
